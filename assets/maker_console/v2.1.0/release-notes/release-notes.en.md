# Gaming Toggles for PC 2.1.0

**Five new actions — seven controls in total.**

- Enter / exit Xbox Mode with Win+F11 on compatible Windows 11 systems with GamingHomeApp configured. No fabricated ON/OFF state.
- Toggle Enhance pointer precision while preserving custom mouse thresholds.
- Switch between two existing power plans selected in the bilingual Property Inspector. The key shows A, B or OTHER.
- **[Labs] Auto HDR** and **[Labs] Windowed game optimizations**: experimental, current-user graphics preferences. Unknown settings are preserved; unexpected formats are not overwritten. Hardware and game support still apply.

Game Mode and Controller opens Game Bar remain available. Stateful actions confirm changes by re-reading Windows and refresh every 2.5 seconds. New actions include high-contrast artwork and English/Spanish labels.

No administrator rights, no telemetry, and no creation, editing or deletion of power plans. Unit, integration, functional, permission, error-handling and regression coverage has been expanded.

**Upgrading from 2.0.0:** the plugin ID remains `com.maecly.gamingtoggles`. Existing 2.0.0 actions keep their IDs; no plugin-ID migration is required. Add the new actions to your profile and configure two installed power plans before using Power plan A / B.
