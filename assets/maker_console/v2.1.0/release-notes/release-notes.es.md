# Gaming Toggles for PC 2.1.0

**Cinco acciones nuevas: siete controles en total.**

- Entrar / salir del modo Xbox con Win+F11 en Windows 11 compatible con GamingHomeApp configurada. Sin inventar un estado ON/OFF.
- Alternar Mejorar la precisión del puntero conservando los umbrales personalizados del ratón.
- Cambiar entre dos planes de energía existentes elegidos en el inspector de propiedades bilingüe. La tecla muestra A, B u OTRO.
- **[Labs] Auto HDR** y **[Labs] Optimizaciones para juegos en ventana**: preferencias gráficas experimentales del usuario actual. Se conservan ajustes desconocidos y no se sobrescriben formatos inesperados. Siguen aplicando los requisitos del hardware y del juego.

Modo Juego y El mando abre Game Bar siguen disponibles. Las acciones con estado confirman los cambios releyendo Windows y se actualizan cada 2,5 segundos. Las nuevas acciones incluyen iconos de alto contraste y etiquetas en español e inglés.

Sin permisos de administrador, sin telemetría y sin crear, editar ni eliminar planes de energía. Se amplió la cobertura de pruebas unitarias, de integración, funcionales, de permisos, de errores y de regresión.

**Actualización desde 2.0.0:** el ID del plugin sigue siendo `com.maecly.gamingtoggles`. Las acciones existentes de 2.0.0 conservan sus IDs; no hace falta migrar el ID del plugin. Añade las nuevas acciones a tu perfil y configura dos planes instalados antes de usar Plan de energía A / B.
