**Siete controles de gaming para Windows, a una pulsación.**

Gaming Toggles for PC lleva los controles de Xbox, ratón, energía y gráficos a Stream Deck. Añade a tu perfil solo las acciones que necesites.

## Cinco acciones Core

- **Alternar Modo Juego** — enciende o apaga el Modo Juego de Windows.
- **El mando abre Game Bar** — permite o impide que el botón Xbox del mando abra Game Bar.
- **Entrar / salir del modo Xbox** — envía Win+F11 para la experiencia Xbox a pantalla completa. Requiere Windows 11 compatible y GamingHomeApp configurada. Es un comando, no un indicador ON/OFF.
- **Mejorar la precisión del puntero** — alterna la aceleración del ratón de Windows conservando tus umbrales personalizados.
- **Plan de energía A / B** — elige dos planes instalados en el inspector de propiedades y alterna entre ellos. La tecla muestra A, B u OTRO; nunca crea, edita ni elimina planes.

## Dos acciones Labs experimentales

- **Auto HDR** — alterna la preferencia de Auto HDR del usuario actual.
- **Optimizaciones para juegos en ventana** — alterna la preferencia de optimización para juegos en ventana del usuario actual.

Labs es experimental: estas preferencias no tienen un setter público estable de Microsoft. Las actualizaciones de Windows o la GPU pueden afectarlas. Se conservan los ajustes desconocidos y no se sobrescriben formatos inesperados. Siguen aplicando los requisitos del juego, la pantalla y el hardware; estos controles no garantizan compatibilidad HDR ni más fotogramas por segundo.

## Estados confirmados

Las acciones con estado releen Windows después de los cambios y se actualizan cada 2,5 segundos. El modo Xbox sigue siendo un atajo sin estado. Los iconos de encendido y apagado se distinguen por luminosidad y forma; los planes tienen indicadores A/B/OTRO diferenciados.

## Requisitos y privacidad

Windows 11 y Stream Deck 7.1 o posterior. Sin permisos de administrador. Usa preferencias del usuario actual, APIs de Windows y planes de energía existentes. Sin telemetría ni servicios externos necesarios; el plugin se comunica localmente con Stream Deck.

Español e inglés según el idioma de Stream Deck. Código abierto bajo licencia MIT, publicado por MAECLY y creado por Miguel Esparza. Las contribuciones son bienvenidas.
