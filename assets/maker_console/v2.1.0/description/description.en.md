**Seven Windows gaming controls, one press away.**

Gaming Toggles for PC puts Xbox, mouse, power and graphics controls on Stream Deck. Add only the actions you need to your own profile.

## Five Core actions

- **Toggle Game Mode** — turn Windows Game Mode on or off.
- **Controller opens Game Bar** — allow or prevent the controller's Xbox button from opening Game Bar.
- **Enter / exit Xbox Mode** — send Win+F11 for the Xbox full-screen experience. Requires compatible Windows 11 and GamingHomeApp configured. This is a command, not an ON/OFF indicator.
- **Enhance pointer precision** — toggle Windows mouse acceleration while preserving your custom mouse thresholds.
- **Power plan A / B** — choose two installed power plans in the Property Inspector and switch between them. The key reports A, B or OTHER; it never creates, edits or deletes plans.

## Two experimental Labs actions

- **Auto HDR** — toggle the current-user Auto HDR preference.
- **Windowed game optimizations** — toggle the current-user windowed-game optimization preference.

Labs is experimental: these preferences do not have a stable public Microsoft setter. Windows or GPU updates may affect them. Unknown settings are preserved and unexpected formats are not overwritten. Game, display and hardware compatibility still apply; these controls do not guarantee HDR support or higher frame rates.

## Feedback you can trust

Stateful actions re-read Windows after changes and refresh every 2.5 seconds. Xbox Mode remains a stateless shortcut. On/off artwork differs in brightness and shape, while power plans have distinct A/B/OTHER indicators.

## Requirements and privacy

Windows 11 and Stream Deck 7.1 or later. No administrator rights. Uses current-user preferences, Windows APIs and existing power plans. No telemetry or external service is required; the plugin communicates locally with Stream Deck.
