Siete controles. Un solo plugin.

El núcleo usa APIs y comandos de Windows sin elevación; dos controles gráficos se publican como Labs porque Microsoft no ofrece todavía un setter público estable.

Alternar Modo Juego

Enciende o apaga el Modo Juego de Windows 11 y confirma el cambio releyendo el valor. Si Windows no lo persiste, la tecla no miente: vuelve al estado real.

HKCU\Software\Microsoft\GameBar
AutoGameModeEnabled

El mando abre Game Bar

Decide si el botón Xbox central del mando puede abrir Game Bar, sin navegar por Configuración. Útil cuando ese botón te interrumpe a mitad de partida.

HKCU\Software\Microsoft\GameBar
UseNexusForGameBarEnabled

Entrar o salir del modo Xbox

Envía el atajo oficial Win + F11. Es una orden deliberadamente sin ON/OFF: Windows no publica un estado fiable para esa sesión.

Windows 11 24H2+ compatible
GamingHomeApp configurada

Precisión del puntero

Activa o desactiva la aceleración del ratón con SystemParametersInfo, conservando los dos umbrales personalizados de Windows.

SPI_GETMOUSE · SPI_SETMOUSE
sin reiniciar ni elevar

Plan de energía A / B

Elige dos planes existentes en el inspector de propiedades. La tecla muestra A, B u OTRO y confirma cada activación.

powercfg /list · /getactivescheme
/setactive únicamente

Labs Auto HDR

Alterna solo el token de Auto HDR y conserva cualquier opción desconocida añadida por Windows o el fabricante de la GPU.

DirectXUserGlobalSettings
AutoHDREnable

Labs Juegos en ventana

Control experimental de las optimizaciones para juegos en ventana. Falla de forma segura si Windows cambia el formato.

DirectXUserGlobalSettings
SwapEffectUpgradeEnable

cada 2,5 s

Siempre refleja Windows

Si cambias la opción desde Configuración, el plugin la relee y actualiza la tecla. En sentido contrario, un notificador en C# emite WM_SETTINGCHANGE para que Configuración se entere al instante.

SendMessageTimeout
HWND_BROADCAST

Preguntas frecuentes

¿Necesita permisos de administrador?

No. Usa preferencias del usuario actual y APIs públicas de Windows. Nunca solicita UAC ni modifica HKLM.

¿Qué versiones admite?

Windows 11 y Stream Deck 7.1 o posterior. El modo Xbox depende de que Windows ofrezca y tenga configurada la experiencia a pantalla completa.

¿Qué significa Labs?

Auto HDR y las optimizaciones en ventana dependen de una preferencia interna documentada por comportamiento, no de un setter público de Microsoft. El plugin preserva campos desconocidos y no escribe ante formatos inesperados.

¿Marketplace y GitHub ofrecen la misma versión?

No necesariamente. La versión indicada aquí y las funciones descritas corresponden a GitHub. Las actualizaciones de Marketplace se publican por separado; consulta la versión y las funciones en su ficha.

¿Es seguro instalarlo desde GitHub?

Cada Release se construye con GitHub Actions, incluye checksum SHA-256 y publica el mismo código que puedes auditar.

¿Puedo contribuir?

Sí. Está bajo licencia MIT y acepta mejoras, pruebas, traducciones e issues en GitHub.
