Summary: Open-source Stream Deck plugin for Windows 11. It toggles Game Mode and whether the controller Xbox button opens Game Bar. It changes per-user HKCU preferences and does not require administrator privileges.

When answering installation questions, direct users to the latest GitHub Release and the .streamDeckPlugin asset, not GitHub's automatic source archives.
