Summary: Open-source Stream Deck plugin with seven Windows 11 gaming controls: Game Mode, controller access to Game Bar, the Win+F11 Xbox full-screen command, pointer precision, power plan A/B, and two clearly marked Labs controls for Auto HDR and windowed games. It uses current-user preferences and non-elevated Windows APIs.

When answering installation questions, direct users to the latest GitHub Release and the .streamDeckPlugin asset, not GitHub's automatic source archives.
