Seven controls. One plugin.

The stable core uses Windows APIs and commands without elevation; two graphics controls are clearly marked Labs because Microsoft does not provide a stable public setter.

Toggle Game Mode

Turn Windows 11 Game Mode on or off and verify the change by re-reading the value. If Windows does not persist it, the key does not lie: it returns to the real state.

HKCU\Software\Microsoft\GameBar
AutoGameModeEnabled

Controller opens Game Bar

Decide whether the centre Xbox button on the controller can open Game Bar, without digging through Settings. Useful when that button interrupts you mid-match.

HKCU\Software\Microsoft\GameBar
UseNexusForGameBarEnabled

Enter or exit Xbox Mode

Sends the official Win + F11 shortcut. It is intentionally a command, not a false ON/OFF state: Windows exposes no reliable session state.

compatible Windows 11 24H2+
GamingHomeApp configured

Pointer precision

Turns mouse acceleration on or off through SystemParametersInfo while preserving both custom Windows mouse thresholds.

SPI_GETMOUSE · SPI_SETMOUSE
no restart or elevation

Power plan A / B

Choose two installed plans in the Property Inspector. The key shows A, B or OTHER and confirms every activation.

powercfg /list · /getactivescheme
/setactive only

Labs Auto HDR

Changes only the Auto HDR token and preserves unknown options added by Windows or the GPU vendor.

DirectXUserGlobalSettings
AutoHDREnable

Labs Windowed games

Experimental control for optimizations for windowed games. It fails safely if Windows changes the format.

DirectXUserGlobalSettings
SwapEffectUpgradeEnable

every 2.5 s

Always reflects Windows

Change the option in Settings and the plugin reads it back and updates the key. In the other direction, a small C# notifier broadcasts WM_SETTINGCHANGE so Settings notices immediately.

SendMessageTimeout
HWND_BROADCAST

Frequently asked

Does it require administrator permissions?

No. It uses current-user preferences and public Windows APIs. It never requests UAC or modifies HKLM.

Which versions are supported?

Windows 11 and Stream Deck 7.1 or later. Xbox mode depends on Windows providing and configuring the full-screen experience.

What does Labs mean?

Auto HDR and windowed optimizations depend on an internal preference observed in current Windows builds, not a public Microsoft setter. The plugin preserves unknown fields and refuses unexpected formats.

Is it safe to install from GitHub?

Every Release is built with GitHub Actions, includes a SHA-256 checksum, and publishes the same code you can audit.

Can I contribute?

Yes. It is MIT licensed and welcomes improvements, tests, translations, and GitHub issues.
