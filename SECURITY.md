# Seguridad / Security

## Reportar una vulnerabilidad / Reporting a vulnerability

No abras un issue público. Envía los detalles de forma privada a
[hola@maecly.com](mailto:hola@maecly.com), incluyendo la versión afectada, los
pasos para reproducir el problema y su posible impacto. El mantenedor revisará
el informe y responderá según disponibilidad.

Do not open a public issue. Privately email
[hola@maecly.com](mailto:hola@maecly.com) with the affected version,
reproduction steps, and potential impact. The maintainer will review the
report and respond as availability permits.

Solo la versión publicada más reciente recibe correcciones de seguridad.

Only the latest published version receives security fixes.
